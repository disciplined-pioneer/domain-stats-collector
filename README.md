# Statistics 301

Автоматизированный скрипт для сбора статистики по доменам с различных платформ (WordPress, DLE, Salexy) и записи этих данных в Google Sheets. Система работает по расписанию, определяя конец дня, недели и месяца, и заполняет соответствующие листы в таблице.

## 📌 Назначение

- Делает GET-запросы к заранее заданным доменам.
- Извлекает ключевые данные (например, редиректы или статус страниц).
- Записывает результат в Google Sheets: **Daily_Stats**, **Weekly_Stats**, **Monthly_Stats**.
- Работает в автоматическом режиме, запускается ежедневно в 23:55 (настройку времмени можно произвести в файле .env - CHECK_INTERVAL_DAILY_CRON)

## ⚙️ Конфигурация

### `.env`

Шаблон конфигурации:

```env
# WordPress
WP_USERNAME=
WP_PASSWORD=

# Google Sheets
GSHEETS_CREDENTIALS_JSON=config/service_account.json
PATH_ALL_DOMAINS_JSON=config/domains_config.json
SHEETS_NAME= # Название таблицы excel

# Запуск скрипта каждый день в 23:55 (cron)
CHECK_INTERVAL_DAILY_CRON = "55 23 * * *"
```

### `domains_config.json`

Пример шаблона (реальные данные не включаются в README):

```json
{
  "Wordpress": ["example1.com", "example2.com"],
  "DLE": ["example3.com"],
  "Salexy": ["example4.com"]
}
```

## 🕒 Расписание

Скрипт запускается ежедневно в **23:55**. Определяет:

- Последний день недели → обновляет **Weekly_Stats**
- Последний день месяца → обновляет **Monthly_Stats**
- В любой день → обновляет **Daily_Stats**

---

## 🚀 Запуск

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Настройте `.env` и `domains_config.json` и service_account.json

3. Запустите скрипт вручную или настройте cron/airflow/systemd:

```bash
python main.py
```

---

## 📈 Google Sheets

Скрипт автоматически создает или обновляет листы:

- `Daily_Stats`
- `Weekly_Stats`
- `Monthly_Stats`

Каждый лист содержит актуальную статистику по доменам в соответствии с датой запуска, а затем добавляет стили

### Описание ошибок

```
1. **404 Not Found** – сервер не может найти запрашиваемый ресурс. Это может быть связано с неправильным URL, отсутствием страницы на сервере или ошибками в настройке веб-сервера.
   
2. **403 Forbidden** – доступ к запрашиваемому ресурсу запрещён. Это может произойти из-за ограничений доступа, таких как защита от ботов, ошибки в настройках прав доступа или неправильно настроенные файлы .htaccess.

3. **500 Internal Server Error** – внутренняя ошибка сервера. Этот код может быть вызван проблемами на сервере, такими как сбой в приложении, ошибка в коде или перегрузка.

4. **502 Bad Gateway** – сервер получил недействительный ответ от другого сервера (например, при использовании прокси или шлюза). Это может быть вызвано проблемами на сервере или в настройках сети.

5. **503 Service Unavailable** – сервер временно недоступен. Это может быть вызвано перегрузкой сервера, его техническим обслуживанием или сбоем в работе зависимых сервисов.

6. **504 Gateway Timeout** – время ожидания ответа от сервера истекло. Это может быть связано с медленным сервером или проблемами в сети.

7. **408 Request Timeout** – запрос не был завершён за отведённое время. Может быть вызвано сетью с низкой пропускной способностью или сервером, который не успевает обработать запрос.

8. **Connection Refused** – соединение отклонено сервером. Это может быть вызвано проблемами с настройками фаервола, сервером, который не слушает на указанном порту, или проблемами в сети.

9. **DNS Lookup Failed (getaddrinfo failed)** – ошибка при разрешении имени хоста в IP-адрес. Это может быть вызвано ошибками в DNS-сервере, неправильными записями DNS или сетевыми проблемами.

10. **SSL Handshake Error** – ошибка при установлении защищённого соединения через HTTPS. Может быть вызвана проблемами с сертификатами SSL, несоответствием версий протоколов или неправильными настройками на сервере.

11. **415 Unsupported Media Type** – сервер не поддерживает тип данных, переданный в запросе. Это может происходить, если Content-Type в запросе не поддерживается сервером.

12. **301 Moved Permanently / 302 Found (Redirects)** – сервер перенаправляет запрос на другой ресурс. Это может быть ожидаемым поведением, но иногда приводит к цепочке редиректов, которая может вызвать ошибку.
```
